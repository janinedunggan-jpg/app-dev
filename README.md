# My Favorite Series: Wednesday 🖤

**Wednesday** is a supernatural mystery comedy series on Netflix based on the character Wednesday Addams from *The Addams Family*.

### Why I Like It:
* **Intriguing Mystery:** The plot keeps you guessing about the monster at Nevermore Academy.
* **Great Cast:** Jenna Ortega delivers an iconic performance as Wednesday Addams.
* **Aesthetic:** Dark, gothic, and witty humor throughout every episode.

> *"I find social media to be a soul-sucking void of meaningless affirmation."* – Wednesday Addams
